# Trading-Nova V1 Product Gap Audit

**Audit type:** source-backed static product-contract review  
**Snapshot audited:** main at a281857a5d47ca6785e93d17f706c755ef1faab7  
**Scope:** locked Product Contract in docs/TRADING-NOVA-MASTER-ROADMAP.md, section 21 (lines 242–283), actual browser UI, HTTP routes, API handlers, engines, persistence, tests, and the external-evidence runbook.  
**Not a certification:** this document does not claim production deployment, profitability, or V1 release approval. Real-money execution must remain disabled.

## Executive finding

The repository has a substantial paper/shadow foundation: private access guard, bounded resource controls, public market-data integration, freshness/stale states, a deterministic Risk Gate, persistent idempotent paper fills, journal integrity, backtest primitives, an AI council, a Roman Urdu tutor, health surfaces, and CI integration checks.

The paper order lifecycle now has durable order records for MARKET, LIMIT, STOP_LOSS and TAKE_PROFIT: pending orders are visible, cancelable while pending, monitored against fresh bid/ask quotes, re-evaluated through the deterministic Risk Gate on trigger, and persisted as FILLED or REJECTED. Restart/replay regression coverage and a user-facing pending/recent-order table are included. This remains a paper simulator, not an exchange-grade matching engine: partial fills, venue-specific queue priority, realistic network latency, replace/amend semantics and independent long-duration durability/production evidence remain open gaps. Stop orders can gap through their trigger; final execution uses the current quote and configured fee/slippage, not a guaranteed trigger price.

Research coverage now has two clearly separated paths: the AI Council remains proxy-based (24-hour momentum, quote-volume and candle-volatility) and continues to report company fundamentals/public news/social sentiment as not connected; the Gemini tutor can use on-demand Google Search grounding and return validated source links for current research questions. The browser chart also receives actual public Binance kline updates over WebSocket. These user-facing paths do not establish a production feed soak, make the AI Council a structured news feed, or enable live-money execution.

## Status definitions

Latest tutor increment (30 October 2026 PKT): the browser has a configuration-only setup check and an explicit sources-required question option. `/api/tutor/status` does not call Gemini or prove connectivity. Sources-required questions fail before outbound work if web research is disabled and withhold the provider answer if no usable grounding links are returned; ordinary educational chat remains available in automatic mode. This does not connect a structured news feed to the council, validate publication freshness or certify the truth of cited claims. Final test/CI and merge evidence is recorded in the matching tutor research-status PR.

- **Implemented + tested:** code path and relevant regression/integration tests are present. This is not the same as external production evidence.
- **Partial:** some code/UI exists, but the locked user-facing behavior or meaningful acceptance evidence is incomplete.
- **Missing:** the required behavior was not found in the inspected runtime/UI flow.
- **External evidence required:** code-level gates may exist, but the claim depends on a real environment, independent review, sustained operation, or explicit human approval.

Priorities: **P0** = correctness/safety mismatch to block before representing that capability as supported; **P1** = core V1 workflow gap; **P2** = important completeness/usability gap; **E** = external certification gate.

## Paper cash currency contract — 30 October 2026 PKT

The browser/API paper account uses a single USDT ledger. Order submission supports USDT-quoted symbols only; the read-only market parser and generic engine remain broader. Non-USDT order requests fail before quote work, legacy pending non-USDT orders are rejected without execution, and legacy non-USDT positions block further execution without silently converting balances. This fixes a reproduced currency-unit mismatch, not a full FX ledger or historical accounting repair. See tests/paper-quote-currency.test.js, tests/ws-d-orders.test.js and the matching PR for final CI/merge evidence.
